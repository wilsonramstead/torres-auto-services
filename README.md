# Torres Auto Services — demo site

Single-page demo site for **Torres Auto Services**, an auto repair & smog shop in
Salinas, CA (4.9★ across 60 Google reviews). Built as a sales demo by Wilson Innovations.

- **Live demo:** https://wilsoninnovations.net/torres-auto-services/
- **Business phone (CTA):** (831) 757-3710 — call/text only, no contact forms
- **Address:** 119 Abbott St, Salinas, CA 93901
- **Hours:** Mon–Fri 8:30 AM – 6:00 PM · Sat 8:30 AM – 5:00 PM · Sun closed

## Build notes
- Single self-contained `index.html`, inline CSS + minimal JS. Works from `file://`
  and with JS disabled.
- **Fonts:** Bowlby One SC (display) + Palanquin Dark (body), via Google Fonts.
- **Palette:** deep cobalt navy + electric blue, with a copper accent.
- **Images:** Unsplash stock (placeholders in the "In the shop" gallery — to be swapped
  for the shop's own photos after sale).
- `noindex` while it's a demo — remove the robots meta when the site goes live.
- Only verified facts from the Google listing are used (name, phone, address, hours,
  rating/review count, and review quotes as testimonials). No invented emails, license
  numbers, founding year, or services.
